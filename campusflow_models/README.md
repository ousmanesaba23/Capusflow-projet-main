# campusflow_models

Package Dart pur (séance 3) qui contient les données de CampusFlow, sans aucune interface.
Il est créé avec `dart create campusflow_models` et sera réutilisé par l'application Flutter.

## Commandes

```bash
dart pub get     # installer les dépendances
dart run         # lancer la démo (bin/campusflow_models.dart)
dart test        # lancer les tests
```
